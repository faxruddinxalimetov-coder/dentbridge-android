# DentBridge — Android

**DentBridge Online** dental laboratoriya, klinika va CAD modelchilar platformasining Android ilovasi.

⬇️ **[DentBridge.apk ni yuklab olish](https://github.com/faxruddinxalimetov-coder/dentbridge-android/releases/latest/download/DentBridge.apk)** (Android 8.0+)

## Imkoniyatlar
- 🔐 **Telefon autentifikatori**: kompyuterda (sayt yoki Windows dasturi) kirilganda so'rov telefonga keladi — tasdiqlaysiz yoki rad etasiz; 30 soniyalik 5 belgili kod
- ⌗ **QR-kod bilan kirish** — parolsiz
- 💻 **Faol sessiyalar** va kirishlar tarixi, istalgan sessiyani yakunlash
- 📋 **Zakazlar** va holati, 💬 **chat**, 🔔 **bildirishnomalar**

## O'rnatish
1. `DentBridge.apk` ni telefonda yuklab oling va oching (kerak bo'lsa, brauzerga «noma'lum manbalardan o'rnatish»ga ruxsat bering).
2. Saytda: Profil → «Kirish va xavfsizlik» → «Telefonni ulash» va QR-kodni ilova bilan skanerlang.
